# Portfolio videos

Place optional `.mp4` files in this folder, then update their paths in `src/data/portfolioData.js`.

- `hero-background.mp4` is used when both `settings.enableVideo` and `hero.enableVideo` are `true`.
- Project videos are used when a project has a `video` property such as `"/videos/project-1.mp4"`.
- When a video is absent, the interface automatically presents the project image with cinematic motion instead.
